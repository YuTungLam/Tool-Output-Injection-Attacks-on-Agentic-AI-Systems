Read measurement definitions and limits

Prior pilot runs are not included in the comparison. Both arms receive the same assigned native injection. Marker counts refer to validated assignment plans, not exposure or propagation. Token and marker totals include only known values; completeness is recorded in the JSON.

The primary execution interval runs from the saved manifest to entry into finalization. It includes primary requests, pacing, native tools and synchronous tracing; it excludes earlier model loading/setup, final artifact export and deferred auditing. Whole worker time includes those other phases. These overlapping times are not additive tracer overhead.

The passive arm has Tier 1 disabled and cannot satisfy the unchanged gate 7 requirement that all four stages are actually scored negative. An unavailable or skipped auditor is not a negative judgment. Routing counts do not measure correct attribution or malicious propagation.

No independent human labels are read or invented. Attribution precision, recall and F1 remain unavailable. No significance, hidden causal attribution, full-paper reproduction or benchmark-wide security benefit is claimed.
