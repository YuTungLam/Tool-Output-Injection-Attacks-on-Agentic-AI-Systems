Executive summary

Under which common agent transformations does the source information survive in the sink while the provenance marker does not?

8/8 final-stage sessions completed their task under the canary condition (model openai/gpt-oss-120b; 29 requests). The attacker address reached the expected sink in 8/8 completed sessions; the runtime canary reached it in 0/8; the tracer's Tier 1 attributed the sink to the marked source in 0/8.

The canary survived in no transformation. Canary lost in every completed run of: Verbatim copy, Field extraction, Paraphrase, Summarisation, Rewrite as memo, Tool-argument construction, Memory write then read (one session), Cross-session memory (two processes). Where Tier 1 misses, the ordered cascade records which later tier matched instead (first-tier column).

The in-content reference line (local placement variant, not a NeuroTaint tier) survived in every completed run of: Verbatim copy, Paraphrase, Rewrite as memo.

Verbatim copy is the placement case: in 1/1 runs the model reproduced the document's content field, including the in-content reference line, but not the YAML metadata block after which the runtime canary is appended, so the canonical marker was dropped even by an exact copy of the document.

Cross-session: lineage status recovered_candidates ×1; Tier 1 attributed 0/1 Session B sends to the recovered file-1 origin. The DCPG rehydrated the graph label (with the original canary reference attached) without the marker text being present in the sink; Tier 2 matched the recovered origin instead.

Prior evidence (runs/20260909-input-comparison-v1): 0/10 Tier-1 hits on composed content; consistent with the transformation results here.

Marker membership is literal and says nothing about maliciousness or causal influence. The canonical placement (a YAML comment appended after the serialized tool result's metadata) is a local choice of the reproduction; the paper says only that a unique UUID is injected into source content.

Limitations

  • One synthetic document, one model, three repetitions per transformation: exact counts for this batch, not rates.
  • The canonical canary placement (YAML comment appended after the serialized tool result) is a local choice; the paper does not specify placement. The in-content reference line is a local placement variant, not a NeuroTaint tier.
  • Marker membership is literal. Information survival is measured by the attacker address and three decision facts only.
  • Prompts explicitly request each transformation; the model's default behaviour under an unconstrained task is not measured here.
  • No clean-document control in this batch; the 2026-09-09 comparison found no passive/canary behavioural difference on a benign task.
  • Nothing here is causal evidence or a defence evaluation; findings concern this reproduction under its declared choices.
